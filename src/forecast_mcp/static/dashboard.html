How this works
  1. Read the forecast. Each gate shows expected arrivals per hour and an 80% range. Orange in the strip below each chart means part of that range comes from limited history: knowledge you have can narrow it.
  2. Try a change safely. Create a what-if and add what you know: a closed gate, fewer lanes, a staff limit, a competing event, a moved show. The plan re-optimizes automatically.
  3. Pick a plan. Each dot on the trade-off is a staffing plan, from cheapest to shortest wait. The whisker shows a bad day. Click one to choose it.
  4. Make it official. Only promoting a what-if changes the official plan. Everything is in the audit log.

In Claude you can do the same by talking. Notes Claude records wait here for your confirmation.
